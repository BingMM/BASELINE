## Later Same-Day Usability Update

The V2 example script could appear hung during long runs because it only printed
before shared plotting and then again after a full mode finished.

Durable runtime observation:

- `save_shared_plots()` can take a long time by itself because it writes a large
  full-year chunk set before variance or baseline estimation starts;
- a first `--mode both` run can also spend a long time computing uncached Step
  1c results for 3 components across both `reference` and `robust`.

Changes made:

- `scripts/example_with_supermag_data_v2.py` now keeps top-level console output
  minimal and no longer emits per-plot-family or per-chunk progress messages;
- `baseline_v2/step1c_reference.py` now shows real `tqdm` compute bars for the
  long baseline stages (Step 1a, Step 1b interpolation, Step 1c, Step 1d
  smoothing/interpolation, Step 2a, and Step 2b smoothing/interpolation);
- `baseline_v2/types.py` now carries simple V2 progress settings for those
  verbose runs.

Practical operator guidance:

- run `python scripts/example_with_supermag_data_v2.py --mode reference` or
  `python scripts/example_with_supermag_data_v2.py --mode robust`;
- later runs should be faster when Step 1c checkpoints are reused.
